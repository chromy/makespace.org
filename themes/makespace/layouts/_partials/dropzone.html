{{- /* Progressive enhancement for the file input on the submission forms. {{ partial "dropzone.html" . }} Dropzone is used only as a picker. It never uploads anything itself: the files it collects are copied into the page's real , and the form posts exactly as it does without JavaScript. That keeps one submission path, one set of validation, and one response to render — the alternative, letting Dropzone POST on its own, would mean a second code path on the server and a second way for it to go wrong. With scripting off, none of this runs and the plain file input is still there. The library is fetched at build time and served from this site, so a visitor makes no request to a CDN.
